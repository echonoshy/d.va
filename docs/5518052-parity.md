## 基准中尚未完成的入口

- Inpainting 只显示施工提示，旧提交没有对应操作。PNG 音色卡嵌入和读取也尚未实现。现有可读写的音色卡格式是 JSON。
- CosyVoice、FireRedTTS、F5TTS 和 Whisper 等源码位于仓库，但该提交未启用对应模型注册或可执行的前台入口。训练页范围为原有的 ChatTTS 音色训练。底层训练模块仍保留。
- 旧 Gradio 分享隧道、Gradio 页面脚本和 Gradio 客户端协议属于被替换的界面。模型接口和 React 页面的入口见 README。

## 复查方式

```sh
npm run build
npm test
uv run python -m unittest discover -s tests
```

Python 测试核对页面、关键操作、旧接口清单、SSML、音色数据及上传音轨。模型音频和一个 epoch 的训练是在安装权重后另行实跑的。音频可播放、时长正常、数值有效只验证功能链路；没有进行真人相似度或长时间训练质量评测。
